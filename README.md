# Subdomain Recon

A lightweight reconnaissance project for discovering and organizing subdomains during authorized web application security assessments.

## Security workflow

```text
Root domain
   ↓
Subdomain discovery
   ↓
Deduplication / organization
   ↓
Validation and enumeration
   ↓
Follow-up security testing
```

## Use cases

- Reconnaissance during penetration testing
- Asset discovery for bug-bounty programs within scope
- Building an inventory of discovered subdomains
- Preparing targets for manual application-security testing

## Methodology

The repository is intended to support the reconnaissance stage of an assessment. Discovery results should be validated before being treated as live assets.

## Security note

Only perform reconnaissance against systems you own or are explicitly authorized to assess. Respect bug-bounty scope, rate limits and program rules.
